Activity 1
1.It can storage more files and documents as references in a large project many people joined in and make team members easier to find and communicate files easier.
2.Different types of files should be storage in different folder. For example, to references, it can save in a Zotero-linked folder; survey data, survey questions and analysis files should be sent into quantitative analysis; draft reports can put into a cloud-synced folder; information sheets, photos, and other media files should in additional materials. If the files have data that is very sensitive and need to be see as a secret, them should be saved in special repository with code and only team members of the team can visit it.

Activity 2
